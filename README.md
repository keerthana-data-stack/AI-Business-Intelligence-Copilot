# AI Business Intelligence Copilot

An AI-powered Business Intelligence platform built with Python and Streamlit that enables users to upload datasets, analyze data quality, generate KPIs, explore correlations, and receive automated business insights.

## Features

- Upload CSV & Excel files
- Automatic data profiling
- Interactive filtering
- KPI generation
- Data Quality Score
- Correlation Explorer
- Executive Insights
- AI-ready architecture

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn (future)
- OpenAI / Anthropic APIs (future)
